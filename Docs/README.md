# petPet — нотатки курсу

Індекс усієї документації в `Docs/`. Відкривається автоматично в режимі перегляду
(Preview) при відкритті `petPet-Notes.code-workspace`.

## Куди дивитись

- [`ROADMAP.md`](ROADMAP.md) — дорожня карта проєкту: що маємо збудувати й навіщо.
- [`Lessons/`](Lessons) — уроки курсу, кожен як окреме завдання (не готове рішення).
- [`ARCHITECTURE.md`](ARCHITECTURE.md) — поточний стан проєкту: хто кого будує,
  ланцюжок FSM, реєстр сервісів, runtime-звʼязки. Живий знімок "як є зараз", без історії.
- [`PATTERNS.md`](PATTERNS.md) — патерн → де в коді застосований, з поясненням чому.
- [`HISTORY.md`](HISTORY.md) — по-уроковий наратив: як і чому код дійшов до поточного вигляду.
- [`Notes/README.md`](Notes/README.md) — довідник C#/Unity понять (generics, делегати,
  reflection, Input System тощо), кожне окремим файлом за задачами.
- [`CV_LOG.md`](CV_LOG.md) — лог навичок/технологій для резюме.
- [`SESSION_NOTES.md`](SESSION_NOTES.md) — короткий підсумок кожної сесії (внутрішня
  робоча нотатка, не для читання як довідник).
